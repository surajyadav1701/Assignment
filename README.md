# JavaScript Assignments & Mini Project

This repository contains all six JavaScript assignments along with the capstone mini project based on the JavaScript curriculum.

## Assignments

### Assignment 1 - Variables, Data Types, and Console Operations
Declares variables using `var`, `let`, and `const` to store a user profile. Uses `typeof` to check and log each variable type.

Run: `node assignment1.js`

### Assignment 2 - Operators, Expressions, and Input Handling
Simulates capturing a bill amount and tip percentage using explicit type conversion. Computes and logs the total bill breakdown.

Run: `node assignment2.js`

### Assignment 3 - Conditional Logic Implementation
Evaluates a numerical test score using `if...else`, assigns a letter grade with `switch`, and uses a ternary operator to determine pass or fail status.

Run: `node assignment3.js`

### Assignment 4 - Loop Control Structures
Prints a multiplication table using a `for` loop, finds the first number greater than 10 divisible by 6 using a `while` loop with `break`, and uses a `do...while` loop with `continue`.

Run: `node assignment4.js`

### Assignment 5 - Function Architecture and Scope
Defines a standard function and an arrow function with default parameters to calculate rectangle area. Demonstrates block scope using `let` inside a block.

Run: `node assignment5.js`

### Assignment 6 - Arrays, Objects, and Core Methods
Creates an array of product objects and uses `forEach()`, `filter()`, and `map()` to print, filter, and transform inventory data.

Run: `node assignment6.js`

## Capstone Mini Project - Interactive Product Inventory & Analytics Dashboard

An integrated console application combining all core JavaScript concepts into one program. It initializes an inventory, simulates user input to add a new product, categorizes each item, calculates total value, filters affordable items, and generates a formatted report.

Run: `node miniproject.js`

## How to Run

Make sure you have [Node.js](https://nodejs.org) installed. Then clone this repository and run any file using:

```bash
node <filename>.js
```
